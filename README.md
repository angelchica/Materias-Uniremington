# 🌌 Explora y Aprende — Portal Académico

Portal web académico con el contenido de las materias vistas en **Uniremington**, construido con HTML, CSS y JavaScript puro, con una estética de *carta estelar* (retícula de coordenadas y red de constelaciones animada).

🔗 **Ver la página:** https://angelchica.github.io/Materias-Uniremington/

---

## ▶️ Cómo verlo

**En línea:** entra al enlace de GitHub Pages de arriba.

**En tu computador:**
1. Descarga o clona el repositorio:
   ```bash
   git clone https://github.com/angelchica/Materias-Uniremington.git
   ```
2. Abre `index.html` en tu navegador.

> **Nota:** si abres la página con doble clic (`file://`), YouTube bloquea el reproductor (Error 153). En ese caso la página de proyecto intenta usar el video local de la carpeta `video/`. Publicada en GitHub Pages, el video de YouTube se ve directamente.
